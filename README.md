 **_QR Code Generator 🔳_**

**📌 Project Description**

QR Code Generator is a Python-based desktop application developed using Tkinter that provides an easy and interactive way to create, customize, save, and scan QR codes. The application has a simple graphical user interface that allows users to generate QR codes from text and URLs, as well as create specialized QR codes for Wi-Fi networks and contact information.

The application also provides customization options such as changing the QR code color and background color, adding a logo/image to the QR code, and saving the generated QR code in image format. In addition, users can scan QR codes using their webcam through OpenCV.

-------------

**✨ Features**

🔗 Generate QR codes for text and URLs

📶 Generate Wi-Fi QR codes

👤 Generate contact/vCard QR codes

🎨 Customize QR code color

🖌️ Customize QR background color

🖼️ Add a logo/image to the QR code

💾 Save QR codes as PNG or JPEG images

📷 Scan QR codes using a webcam

🗑️ Clear generated QR codes and input

🌙 Dark mode and ☀️ light mode

🖥️ User-friendly Tkinter graphical interface

⚡ Automatically saves generated QR codes as my_qr_code.png

----------

**🛠️ Technologies Used**

Python – Core programming language

Tkinter – Graphical User Interface

QRCode – QR code generation

Pillow (PIL) – Image processing and logo integration

OpenCV – Webcam-based QR code scanning

---------

**🎯 Project Objective**

The main objective of this project is to develop a convenient desktop application that allows users to generate and manage different types of QR codes without relying on an online QR code generator. The project also demonstrates practical implementation of Python GUI development, image processing, file handling, QR code generation, and computer vision.

--------

**🚀 How to Run**

Install the required libraries:

pip install qrcode[pil] pillow opencv-python

Run the application:

python QR_Generate.py
